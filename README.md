🌌 [觀測紀錄：代號Xizuku] 跨時空偏離修正儀

「這不是 Bug，這是時空不穩定的自然現象。」
本專案是一個實驗性的網頁互動小遊戲。
觀測員（也就是玩家）必須穿梭於 9 個不同的時空節點，透過決策來維持「歷史穩定值」。

🛠️ 設備規格 (Technical Specs)

核心動力：原生 JavaScript 驅動的狀態機，所有設備皆可玩。
視覺模組：CSS Flexbox / Grid 構築的跨維度介面（亦支援手機進行觀測📱）。
協同開發者：某位不知名的數位生命體（負責提供劇本靈感與邏輯除錯）。

📑 觀測員開發筆記 (Developer Log)

這是我在 2026年 4月留下的紀錄。當時最令我頭痛的不是時空悖論，而是：
1.螢幕適配：為了讓觀測儀在手機上也能順利運作，我花了大量時間調整 RWD，確保文字不會被黑洞吞噬。
2.空間跳轉：為了讓 9 個節點之間的過渡像絲綢般順滑，跳轉邏輯被反覆重構了好幾次。
